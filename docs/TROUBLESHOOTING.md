# 故障排查

## 首次打开被 macOS 阻止

当前应用尚未经过 Apple Developer ID 签名和公证，浏览器下载可能触发系统拦截。先确认下载来自本项目 Release；安装包附有 SHA-256 校验文件。

可参考 [Apple 的安全打开说明](https://support.apple.com/zh-cn/102445) 自行判断是否信任此应用。不要关闭 Gatekeeper、SIP 或全局安全保护。由组织管理的 Mac 可能受额外限制，不能保证可以运行。

## 点击开启后提示找不到官方应用

先从 [Wispr Flow 官网](https://wisprflow.ai/downloads) 安装、登录官方原版，并保持路径 `/Applications/Wispr Flow.app`。汉化不会替代官方应用，也不包含订阅授权。

## 官方签名检查失败

请使用官网原版替换曾被修改、直接汉化或重新签名的版本。不要删除账号资料或听写记录。本补丁不会自动给修改版重新签名。

## 提示 Wispr Flow 无法退出

请结束录音并正常退出 Wispr Flow，再点击按钮重试。补丁只请求正常退出，不会强制结束。

## 辅助功能已经打开，仍提示未授权

确认使用官方签名版本，并在“系统设置 → 隐私与安全性 → 辅助功能”里检查 **Wispr Flow**，不是 Node 或本补丁。如果系统保留失效的旧条目，可按官方提示重新选择 `/Applications/Wispr Flow.app` 授权。

不需要给补丁新增辅助功能、麦克风或完整磁盘访问权限，不要重置整个系统权限数据库。

## 菜单栏显示开启，部分页面仍英文

顶部原生菜单、部分系统提示或新增词条不在当前覆盖范围。手动完整刷新页面后可能需要退出重开。官方大幅改版也可能需要适配。

## 开启后卡顿

先通过菜单栏关闭中文，用相同操作对比官方界面。本项目保持 Interactive 调度策略，避免 GUI 应用继承后台限速；每页加载后断开调试会话，没有常驻词库观察器。

提交问题时提供系统版本、芯片、应用版本和复现步骤即可，不要上传听写正文、账号资料或令牌。

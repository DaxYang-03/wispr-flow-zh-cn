# 安装与使用排查

## 下载后没有 node 或 wispr-launch

下载的是源码，或 ZIP 没有完整解压。请到 [Releases](https://github.com/DaxYang-03/wispr-flow-zh-cn/releases/latest) 下载名字包含 `macOS.zip` 的安装包，不要用 GitHub 的 Source code ZIP。不要只移动单个 `.command` 文件，四个工具需要和 `bootstrap.sh`、`app/`、`runtime/` 在同一文件夹。

## 提示“请先完全退出”

关闭窗口后 Wispr Flow 可能仍在菜单栏运行。从应用菜单选择 Quit 完全退出，再运行安装或停用工具。安装器会主动拒绝中断正在使用的应用。

## 被 macOS 阻止、提示无法验证开发者或已损坏

此项目的启动小程序尚未做 Apple Developer ID 签名和公证，浏览器下载可能触发 Gatekeeper。先确认文件来自本项目 Release，并对照 `SHA256SUMS.txt` 校验下载；不要关闭 Gatekeeper、SIP，也不要使用全局移除隔离属性的命令。

可使用 [README 的终端安装方式](../README.md#方式一复制到终端安装)。对系统提示的含义和是否信任软件有疑问时，查看 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。组织管理的 Mac 可能受额外策略限制，不能保证可以安装。

## 官方签名检查失败

补丁不会自动给被修改的应用补签名。如果以前安装过直接修改应用内容的汉化版，请从 [官网](https://wisprflow.ai/downloads) 安装官方原版，并保持路径 `/Applications/Wispr Flow.app`。然后再次安装本助手。不要删除账号资料或听写历史目录。

## 辅助功能已经打开，应用仍显示未授权

先完全退出后重开。确认安装的是官方签名版本，并在“系统设置 → 隐私与安全性 → 辅助功能”里检查 **Wispr Flow**，不是 Node 或中文助手。如果系统保留了失效的旧条目，可按照官方应用提示重新选择 `/Applications/Wispr Flow.app` 授权。

不需要给中文助手额外权限，不要重置整个系统权限数据库。状态工具显示的是最近一次应用启动检测；你后来改变权限后，记录可能尚未更新。

## 部分页面英文或重开后才有中文

确认助手启用并等待数秒。原图标启动时会在早期接管重开一次；已运行较久的应用不会被强行重启，需自行退出再开。顶部原生菜单仍英文属于已知范围限制。手动完整刷新页面后需要退出重开。

如果新版本持续无法加载，先停用助手恢复官方界面，再提交系统版本、应用版本和复现步骤。未来架构改变可能需要适配，不能用继续重新签名应用来解决。

## 卡顿或掉帧

本项目的登录服务必须使用 `ProcessType=Interactive`。不要将它改成 `Background`；这会让被启动的 GUI 应用继承资源限制。发行版已经采用正常策略，且每页加载完成后会断开调试会话。

如果仍卡顿，请先完全退出，运行恢复英文工具，再用相同操作比较官方界面。只暂停助手进程不足以移除已经加载到页面里的译文。提交问题时说明两种状态的对照结果即可，不需要上传听写记录。

## 卸载后还有目录

恢复工具有意保留词库。停用后可以把 `~/Library/Application Support/Wispr Flow 中文助手/` 移到废纸篓。官方应用和其账号数据没有被修改。

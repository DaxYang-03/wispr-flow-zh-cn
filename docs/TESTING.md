# 测试范围和已知边界

## 已有真实设备证据

原始测试环境：Apple Silicon、macOS 27.0、Wispr Flow 1.6.1337。

- 官方代码签名完整校验通过；汉化不修改官方应用。
- 应用自己的辅助功能状态接口返回已授权，系统日志归属为官方应用。
- 首页、设置和其他应用内页面显示中文。
- v0.1.1 的完整安装文件已在原始设备实际运行：只运行安装入口，程序自动打开中文首页并报告成功，没有再调用独立启动工具。
- 正常退出不会被助手自动重开。
- 从原图标启动可自动接管并加载中文。
- 用同版本官方应用整包替换后，已有译文重新加载。
- 曾出现中文启动后掉帧；只暂停轮询和断开页面会话未解决。将登录服务从 Background 改为 Interactive 后，用户确认恢复流畅。

这些证据来自项目最初在设备上的开发验证，不代表所有发行安装包在所有 Mac 上都已实际安装测试。

## 自动化验证

- 7,264 条记录的键覆盖、占位符、标记和 URL 校验。
- Webpack 模块编号变化、延迟初始化、词条编号变化的模拟测试。
- 新增英文词条保留；同原文冲突时不强制回退翻译。
- 一次加载方案不安装观察器、只广播一次语言刷新。
- 中文和带空格/特殊字符的用户目录。
- 安装器在应用运行或签名无效时，不能停止服务或写入安装目录。
- 安装后自动发起一次启动，并确认本次中文已加载；旧成功记录或启动失败不会被当作成功。
- 停用时保留译文，移除登录项。
- 启动配置包含 Interactive，防止后台限速回归。
- 发布包中两种 Node.js 下载档案经过官方 SHA-256 校验；小程序包含 arm64/x86_64。

安装器文件操作测试在临时目录中使用明确的假进程和假签名结果，不操作真实系统登录项。持续集成只验证代码和构建，不录音、不授权、不运行真实应用。

## 尚未验证或明确不支持

- Intel Mac 上的真实应用 UI、权限、性能；虽然提供了 Intel 运行环境和通用启动小程序。
- 所有 macOS 13.5+ 系统组合、企业 MDM 限制和浏览器隔离提示组合。
- 真实的未来 Wispr Flow 发行版本；整包替换测试使用同一个已验证的官方版本。
- 顶部原生菜单和主进程系统提示，不在页面词库覆盖范围。
- 官方架构更换后的永久兼容，以及词条编号/原文同时改变后的自动翻译。

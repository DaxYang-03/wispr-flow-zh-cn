# 实现原理与限制

中文助手在官方应用启动时，将已有译文叠加到页面的显示词库。译文保存在应用外，官方应用更新不会覆盖它。每次启动重新识别模块：先按词条编号复用，再对同一词库内无歧义的相同英文原文复用。新增内容可以保持英文。

- 保留官方应用文件和签名，不修改应用偏好或权限数据库。
- 使用本机私有进程管道，不开放网络调试端口。
- 每页只加载一次，成功后断开该页面的调试会话；不安装常驻词库观察器。
- 登录服务使用 Interactive，避免 GUI 应用继承后台限速。
- 启动小程序保持权限归属为官方 Wispr Flow，不需要给中文助手额外的辅助功能、麦克风或完整磁盘访问权限。
- 助手自身只记录启动、注入条数、断开状态和授权布尔值，不上传页面正文、听写内容或账号资料。官方应用自身的联网行为由官方应用决定。

## 兼容范围

词库保存了 7,264 条记录，不代表所有词条都在全部界面生效。顶部 macOS 原生菜单和主进程系统提示不在此方案覆盖范围。

同版本官方应用整包替换、模块编号改变、词条编号改变和新增英文词条已经测试。未来更换界面技术、签名团队、调试能力、词库结构，或同时改变词条编号和原文，都可能需要适配。

从原图标启动时，助手可能在启动初期接管重开一次；请稍等数秒再开始录音。已经运行较久的实例会保持不动，不强行中断。手动完整刷新页面后译文可能消失，需要完全退出再打开。

助手进程退出可能导致管道启动的应用退出，因此更新或停用助手前，安装器仍会要求先完全退出 Wispr Flow。
